Flutter · Android · DIA ERP

Depo mobil uygulamaları (3 müşteri)

Gıda ve perakende firmalarının depolarında personel, el terminaliyle mal kabul, sevkiyat ve depolar arası transfer yapıyor. İnternet her zaman yok; o yüzden uygulamayı offline çalışacak şekilde tasarladım. Sipariş ve okutmalar cihazda tutuluyor, bağlantı gelince DIA’ya sırayla gönderiliyor.

Üç müşteride aynı omurga var ama belge modeli farklı: birinde klasik irsaliye, diğerinde sevkiyatta teslimat çıkış fişi, birinde lot/seri okutma ve Honeywell desteği. Ortak kısım Riverpod, Hive, SyncEngine, Firebase ile çok kullanıcılı görünürlük ve Zebra DataWedge barkod. Güncellemeleri Play Store olmadan Drive üzerinden OTA ile dağıttım.

  • Mal kabul / sevkiyat / transfer akışları uçtan uca
  • Kısmi aktarım, birim seçimi, miktar girişi, saklanan belgeler
  • DIA Web Servis v3 (sipariş, irsaliye, malzeme fişi, rapor)
  • UAT ve sürüm doğrulama ile canlıya alma

Flutter, Dart, Riverpod, Hive, Dio, Firebase, DIA WS v3

Market sipariş otomasyonu (Bizofis → DIA)

Marketlerden gelen siparişler daha önce elle DIA’ya giriliyordu; hem yavaş hem hata riski yüksekti. Bizofis / ECOD EDI üzerinden siparişleri çekip listede gösteren, filtreleyen ve seçilenleri DIA’da alınan sipariş olarak açan bir web aracı yazdım.

A101, BİM, FİLE ve Yemek Sepeti taraf/GLN eşlemesi, mağaza adı eşlemesi, stok eşlemesi ve aktarım sonrası fiş no takibi var. Tekli veya toplu aktarım yapılabiliyor; tekrar çekimde gereksiz çağrı olmasın diye yerel cache kullandım. Giriş Firebase Auth ile.

  • Yeni sipariş / tüm sipariş çekimi
  • Market filtresi, arama, detay ekranı
  • DIA login + scf_siparis_ekle entegrasyonu
  • Aktarıldı işaretleme ve izlenebilir fiş referansı

Node.js, Express, Vanilla JS, XML/EDI, Firebase, DIA WS

React · TypeScript · .NET 9

Havuz fatura aktarım paneli

Havuz firmadaki faturaların hedef firma, şube, depo ve döneme kontrollü aktarılması gerekiyordu. React arayüz ve .NET 9 Web API ile tek panelde liste, durum ve aktarım akışını kurdum.

Fatura bazlı veya kalem bazlı (dağıtılacak) seçim yapılabiliyor. Bekliyor / kısmi / aktarıldı durumları ekranda net; hata olursa tekrar dene, paralel gönderim ve sunucu tarafında mükerrer kayıt engeli var. Son aktarılan kayıtlar aynı ekranda takip ediliyor.

  • Hedef firma / şube / depo / dönem seçimi
  • Durum rozetleri ve son aktarım geçmişi
  • DIA fatura aktarım API’si + Firebase oturum
  • Retry ve dedup ile güvenli gönderim

React 19, Vite, TypeScript, Tailwind, .NET 9, Firebase, DIA WS

Okul projesi · .NET 8 · React · Docker

ToyLand · mikroservis e-ticaret

Üniversite mikroservisler dersi için geliştirdiğim e-ticaret uygulaması. Klasik tek uygulamada her şeyi yapmak yerine kimlik, katalog, sepet, sipariş ve indirimi ayrı servislere böldüm; React mağaza arayüzü API Gateway üzerinden bu servislere istek atıyor.

Backend .NET 8, frontend React, tüm ortam Docker Compose ile ayağa kalkıyor. Giriş/kayıt, ürün listesi, sepet ve sipariş ekranlarını uçtan uca çalışır hale getirdim.

  • Mikroservis mimarisi + API Gateway
  • JWT kimlik, Redis sepet, RabbitMQ, gRPC
  • .NET 8 · React · Docker
